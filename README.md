# Smart City Super App (Flutter Frontend) 🏙️🚀

تطبيق المدينة الذكية المتكامل (Smart City Mobile Super App) المبني باستخدام فريمورك **Flutter** والمتصل بالسيرفر السحابي المباشر لقاعدة بيانات وخدمات المدينة الذكية.

## 🌟 مميزات التطبيق
- **فحص الاتصال السحابي المباشر** بالسيرفر السحابي (Railway Cloud API).
- **لوحة القطاعات الذكية التسعة**:
  1. 🛒 المتاجر والتسوق الذكي (Smart Retail)
  2. 🏥 العيادات والرعاية الصحية (Smart Health)
  3. 🚌 النقل والمواصلات التشاركية (Smart Transport)
  4. ⚡ الطاقة والمرافق العامة (Smart Utilities)
  5. 🎓 التعليم والتدريب التفاعلي (Smart Education)
  6. 🏢 الخدمات الحكومية والبلدية (Smart Governance)
  7. 🛡️ الأمن والسلامة والطوارئ (Smart Safety)
  8. ☕ السياحة والضيافة والترفيه (Smart Tourism)
  9. 🌐 الميتافيرس والتوأم الرقمي 3D (Metaverse & Unity Hub)
- **إنشاء وإدارة التجار والأنشطة** مع ربط كامل مع الـ REST API.
- **عرض حالة السيرفر وزمن الاستجابة**.

## 🛠️ متطلبات التشغيل
- Flutter SDK (الإصدار 3.0 فما فوق)
- جهاز محاكي أندرويد / هاتف ذكي / أو تشغيل مباشر على Chrome أو Windows Desktop.

## 🚀 طريقة التشغيل
1. استنساخ المستودع:
```bash
git clone https://github.com/<YOUR_USERNAME>/smart_city_flutter_app.git
cd smart_city_flutter_app
```
2. تثبيت الحزم:
```bash
flutter pub get
```
3. تشغيل التطبيق:
```bash
flutter run
```
